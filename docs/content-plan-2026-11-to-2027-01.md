Rules that every slot passed or must pass before writing:
1. Creation intent (AGENTS.md "Check search intent"). Definition-only topics are
   allowed only where the post is built to be cited by AI answers *and* links a
   creation page — marked **AI**.
2. Measured demand. **V** = verified volume (DataForSEO 2026-10-13, or Semrush
   2026-08 where noted). **U** = unverified — waits for one DataForSEO
   search_volume call (needs a balance top-up; the account hit $0 on
   2026-10-13).
3. Ownership gate: no /brands, /templates or existing post already ranks for it
   (GSC query→page, Jul 15 – Oct 12). Checked for V rows.
4. Owner decision 2026-10-13: tax/legal/financial posts keep the current practice
   — name the authority (IRS, HMRC, USPS, state DMV…), add a not-advice note,
   publish on schedule. No separate review gate.
